# Burger Studio

A groovebox app for Android, made to play together with the FM-1:
sample tracks with a step sequencer, drum pads, bass and analog synth,
a vocal channel, song parts and mix recording.

## Get the app

Every push to `main` builds a new APK. Download `burgerstudio-debug.apk`
from the **Releases** page (release "latest") and install it on your phone.
A new version installs over the old one and keeps your work.

## Notes

- The package name stays `com.example.fm1burger` so updates keep installing
  over earlier versions of the app.
